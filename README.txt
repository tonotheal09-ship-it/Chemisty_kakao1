# 카카오톡 개인 아카이브

이 폴더 전체를 GitHub Repository에 올리고 GitHub Pages를 켜면 됩니다.

## 구조
- `index.html` : 연도/월 목록
- `months/YYYY-MM.html` : 해당 월의 전체 대화와 월별 검색

## GitHub Pages
1. GitHub에서 새 Repository 생성
2. 가능하면 Private Repository로 보관
3. 이 폴더의 모든 파일을 Repository에 업로드
4. Settings → Pages
5. Source를 GitHub Actions 또는 Deploy from a branch로 설정
6. `main` / `/ (root)`를 선택
7. 생성된 Pages 주소에서 `index.html` 접속
